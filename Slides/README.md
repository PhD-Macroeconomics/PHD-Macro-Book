# Slides

Lecture slides accompanying [*Macroeconomics*](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026).
| Folder | Contents |
|---|---|
| **[PDF-Slides](PDF-Slides)** | Compiled decks, ready to present |
| **[Source](Source)** | LaTeX/Beamer sources for the same decks, with their figures |

The decks follow the book chapter by chapter, but they are not a script. They are meant to
be adapted: if you teach a chapter in a different order, spend longer on one model, or want
to drop a section, start from the source rather than the PDF.

Slides are added as chapters are finalised, so not every chapter is here yet.
