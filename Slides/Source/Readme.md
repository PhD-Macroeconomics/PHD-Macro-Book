# Slide sources

LaTeX/Beamer sources for the lecture slides accompanying [*Macroeconomics*](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026).

## Instructions 

Each chapter has its own folder holding the `.tex` file for that chapter's deck, the
compiled `.pdf`, and a `SlideFigures` sub-folder with the figures the deck reads.

To adapt a deck, take the whole chapter folder. The `.tex` file expects its figures to sit
alongside it in `SlideFigures`, so it will not compile if you copy the `.tex` on its own.
