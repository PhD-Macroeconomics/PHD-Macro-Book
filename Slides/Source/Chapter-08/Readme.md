# Chapter 8 — Empirical strategies and quantitative macroeconomics

LaTeX source for the slides accompanying Chapter 8 of [*Macroeconomics*](https://phdmacrobook.org/), together with the
compiled PDF.

Figures are in the [`SlideFigures`](SlideFigures) sub-folder and the `.tex` file reads them from
there, so take the whole folder if you want to recompile or adapt the deck.
