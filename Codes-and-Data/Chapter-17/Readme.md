# Chapter 17

This folder includes codes to accompany Chapter 17 "Money" written by Andreas Hornstein and Per Krusell of the book [Macroeconomics](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026). 

The data and code for Figures 17.3 and 17.4 is attached. There are no other codes associated to this chapter.
