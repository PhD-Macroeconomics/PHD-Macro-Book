# Chapter 19

This folder includes codes to accompany Chapter 19 "Credit market frictions" by Vincenzo Quadrini of the book [Macroeconomics](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026).

These codes were written by Vincenzo Quadrini.

## The codes

Computation.pdf explains how to solve for the general equilibrium using the Projection Method. The codes used to solve the model are written in Fortran, while the code
used to construct the graphs is written in GAUSS. 

These are the code files:

* MainProg.f90 – File containing the Fortran code for the main program.
* Param.f90 – File containing the predefined parameters written in Fortran.
* Routines.f90 – File containing various functions written in Fortran.
* Simulation Procedures.f90 – File containing the Fortran subroutines that simulate the model after a solution has been found (the
function g(s)).
* MakePlot.gau – GAUSS code that uses the data generated by the
Fortran code to construct the simulation graphs.

## Instructions to run them:
1. Save the first four files (MainProg.f90, Param.f90, Routines.f90,
Simulation Procedures.f90) in a directory.
2. In the same directory where you saved the above files, create a subdirectory
named Simulation. In this directory, the Fortran code will
save various files containing the data generated through the simulation
of the model. These data files will be used to construct the graphs.
3. In the subdirectory Simulation, save the GAUSS code MakePlot.gau.
4. Compile the Fortran file MainProg.f90.
5. Run (execute) the executable file created by compiling MainProg.f90.
When the execution finishes, the model will have been run and simulated.
At this point, you will see new files stored in the subdirectory
Simulation.
6. To construct the graphs, run the GAUSS program MakePlot.gau that
you previously saved in subdirectory Simulation.
