# Chapter 22

This folder includes codes to accompany Chapter 22 "Heterogeneous Firms" written by Toshihiko Mukoyama of the book [Macroeconomics](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026) .

These codes were written by Toshihiko Mukoyama.

## Instructions

The zip file codes_Chapter22.zip contains two folders. "Calibration" is the fortran program (and its output) for calibrating the model. "Experiments" folder contains the fortran program for the counterfactual experiments and output files for each experiment.

The zip file data_Chapter22.zip contains all data for figures.
