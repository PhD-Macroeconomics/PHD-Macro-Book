# Chapter 20

This folder includes data to accompany Chapter 20 "Frictional Labor Markets" written by Toshihiko Mukoyama and Aysegul Sahinof the book [Macroeconomics](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026).  

The codes were written by Toshihiko Mukoyama and Aysegul Sahin.

## Instructions
The zip file codes_Chapter20.zip contains two folders. "Matlab" contains the matlab files for Tables 20.3-19.6. "NGMflex" is the fortran program (and its output) for the neoclassical growth DMP Model (Section 20.8.1). "NGMrigid" folder contains the fortran program for the rigid wage case (Section 20.8.2).

The zip file data_Chapter20.zip contains all data for figures.
