# Code and data

Code and data reproducing the figures, tables, and quantitative results in [*Macroeconomics*](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026).

Each chapter has its own folder with a README describing what the files do, in what order
to run them, and what they produce. Where a chapter's results rest on a numerical method
rather than a closed-form solution, the code is the clearest statement of how the model was
actually solved, and is worth reading alongside the text.

The code is written in MATLAB, Stata, Python, Fortran, and GAUSS, depending on the chapter.
Individual chapter READMEs note what a particular set of files needs.

Chapters 1,4 5, 6 and 9 do not contain associated codes or data so there are no corresponding folders in the this repository.
