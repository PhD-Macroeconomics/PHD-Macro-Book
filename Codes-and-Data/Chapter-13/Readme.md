# Chapter 13

This folder includes codes to accompany Chapter 13 "Growth" written by Timo Boppart and Peter J. Klenow of the book [Macroeconomics](https://phdmacrobook.org/), by Marina Azzimonti, Per Krusell, Alisdair McKay, and Toshihiko Mukoyama, plus contributing authors (Oxford University Press, 2026).  

These codes were written by Timo Boppart and Peter J. Klenow.

### This folder contains all the files needed to generate the figures and tables for Chapter 11 of the textbook.

- All plots are created by running the script named plots.ipynb.

- All tables are produced by running the script named tables.ipynb.

- Figures are saved in both black & white and color formats.

- The data used to create each plot is saved in Excel format in the Output folder. You can use the Figures' Directory Table to find the related output file for each figure.

- LaTeX versions of the tables are saved in the Tables folder. Use the Tables' Directory to find the LaTeX code for each table
